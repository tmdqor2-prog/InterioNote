✂ 카드 분할

한 카드 안에 두 사람 발화가 섞여 있을 때 사용합니다. 자르고 싶은 위치를 텍스트 안에서 클릭하면 그 자리에 ┃ 표시가 나타나고, "여기서 분할" 누르면 두 카드로 나뉘어 각자 화자 라벨을 따로 줄 수 있습니다.

분할 위치: / 전체 글자
왼쪽 카드 (원본)
오른쪽 카드 (새로 생김)

⌨️ 단축키

  • 1 카드 라벨 = 나
  • 2 카드 라벨 = 고객
  • 0 카드 라벨 지우기
  • / 또는 F3 카드 검색 열기
  • F1 이 도움말 토글
  • Esc 검색·도움말·편집 닫기
텍스트 입력 중에는 1·2·0 단축키가 동작 안 합니다 (정상).
