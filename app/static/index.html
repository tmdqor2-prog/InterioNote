📘 빠른 사용법

  • ① 신규 고객은 좌측의 ✨ 새 고객 상담 시작 → 이름·평형 입력 → 자동 폴더 생성
  • ② 기존 고객은 아래 목록에서 클릭 → 상담 종류(초도·디자인·견적) 선택 → 녹음 시작
  • ③ 녹음 중 발화 카드가 1~3초 뒤 자동 생성. 1=나, 2=고객, 0=라벨 지우기
  • ④ 종료 후 🎯 정확도 재처리 (medium) 로 인식률 향상, ✨ AI 분석 으로 요약 생성
  • ⑤ 저장 위치·폴더 구조·모델 등은 우측 상단 ⚙️ 설정 에서 변경
