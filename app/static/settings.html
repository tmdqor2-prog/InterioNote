📦 백업 복원 방법
  1. InterioNote 종료 — 작업표시줄에서 우클릭 → 닫기 (또는 작업관리자에서 InterioNote.exe 종료)
  2. 백업 zip 압축 풀기 — 백업 파일 우클릭 → 압축 풀기
  3. DB 파일 덮어쓰기 — 압축 푼 폴더의 data/interionote.db 를 %APPDATA%\InterioNote\data\ 폴더에 덮어쓰기 (옛 DB 자동 백업 권장)
  4. 앱 재시작 — 모든 고객·상담·태그·OJT 매핑이 복원됨
⚠ 고객 폴더 (07_고객정보, 녹음 mp3·요약 md 등) 는 본 백업에 포함 안 됨 — OneDrive·외장 으로 별도 보관 필요.

🔗 다중 PC 동기화 가이드 — OneDrive 로 노트북↔데스크탑 실시간 공유

💡 InterioNote 의 고객 폴더 루트를 OneDrive 안에 두면, 두 PC 가 자동으로 같은 데이터를 공유합니다.
DB 와 설정은 각 PC 에 독립 보관되어 녹음·전사는 각자 실행되고, 저장 파일(MP3, 요약 등)만 공유됩니다.
  1. 1
    OneDrive 폴더 위치 확인
    파일 탐색기에서 OneDrive 폴더를 찾습니다. 보통 C:\Users\{이름}\OneDrive 입니다.
  2. 2
    고객 폴더 이동 (처음 설정 시만)
    기존 고객 폴더 전체를 OneDrive 안으로 옮깁니다. 예: OneDrive\고객정보 로 이동.
    ⚠ 이동 중 앱을 실행하지 마세요. 이동 후에 아래 3단계 진행.
  3. 3
    이 화면에서 고객 폴더 루트 변경
    위 탭 → 사용자 폴더 탭 → 📂 찾아보기 로 OneDrive 안의 고객 폴더를 선택 후 저장합니다.
  4. 4
    다른 PC 에도 InterioNote 설치
    다른 PC 에서 InterioNote 를 설치하고, 위 3단계와 동일하게 같은 OneDrive 고객 폴더를 루트로 지정합니다.
  5. ✓
    완료 — 두 PC 가 같은 고객 데이터 공유
    이후 어느 PC 에서 녹음해도 MP3·요약·전사 파일이 OneDrive 를 통해 다른 PC 에서도 보입니다. 단, 홈 화면 고객 목록은 각 PC 가 폴더를 다시 스캔해야 최신으로 표시됩니다.
⚠ 동시 녹음 주의: 두 PC 에서 같은 고객 폴더에 동시에 녹음하면 파일 이름이 겹칠 수 있습니다. 한 번에 한 PC 에서만 녹음하세요.

🔇 노이즈 억제 (silero-denoise)

매장 음악·잡음을 AI 모델(silero-denoise)이 실시간으로 제거합니다. 변경 후 다음 녹음부터 반영됩니다. 조용한 환경에서는 꺼두면 CPU 부담이 줄어듭니다.
· 첫 사용 시 모델 자동 다운로드 (~52MB, 인터넷 필요)
· CPU 부담: 100ms 블록당 약 30~60ms 추가 처리
· 카드 표시까지 0.3~0.5초 정도 더 걸릴 수 있음
· 저장된 MP3 도 노이즈 제거된 음원으로 저장됨 (재생 시 더 깨끗)
